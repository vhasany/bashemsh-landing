# BASHEMSH — Official Brand Assets

Approved Royal Luxury identity for **باشمش / BASHEMSH**.

## Logo files
- `logos/bashemsh-royal-logo.svg`: approved vector Persian wordmark, original letter dots, single crown above meem, and BASHEMSH Latin signature.
- `logos/bashemsh-crown-favicon.svg`: small-use crown icon.
- `logos/bashemsh-logo-on-dark.svg`: logo on near-black brand background.
- `logos/royal-corner-ornament.svg`: ornamental gold corner detail (not itself the brand mark).

## Palette
- Background: `#080706`
- Champagne gold: `#e6bd70`
- Warm ivory: `#f8f1df`

## Usage
Use original SVG for print and scalable digital display. Keep original Persian dots and **one** crown above the meem. Do not stretch, crop, or alter the lettering.

The lion-background social media PNG pack, business-card artwork, and print files are **not included here** yet. These binary assets are retained separately and must be uploaded after verification; don't substitute concept mockups for production-ready artwork.

The existing live site is unchanged by this asset folder.
